# Fortnite Box Tracker

Личный счётчик открытых ящиков Fortnite. Это PWA: сайт можно установить через браузер как приложение.

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub и загрузи **все четыре файла** из этой папки в корень: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
2. Открой **Settings → Pages**.
3. В **Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажми **Save**.
4. Дождись публикации. Открывай сайт по адресу `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Установка на телефон
Открой опубликованный сайт в Chrome. Нажми меню ⋮ → **Установить приложение** или **Добавить на главный экран**. На некоторых устройствах кнопка установки появится прямо на сайте.
На iPhone открой сайт в Safari → Поделиться → **На экран «Домой»**.

Установка требует HTTPS (GitHub Pages его предоставляет). Счётчик хранится локально в браузере/приложении на этом устройстве; очистка данных браузера может удалить его.
