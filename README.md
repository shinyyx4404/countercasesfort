# Fortnite Box Counter

Личный счётчик открытых ящиков Fortnite. Работает как статический сайт, без сервера.

## Запуск
Открой `index.html` в браузере.

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория файл `index.html`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через некоторое время сайт появится по адресу `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Счётчик сохраняется в localStorage браузера на текущем устройстве. Очистка данных браузера может удалить сохранённый прогресс.
